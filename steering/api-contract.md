# 接口方向（api-contract）

规范性路径、请求字段、完整响应、错误码与角色矩阵见 [APIC](../docs/APIC.md)。所有受保护接口复用会话、Origin/CSRF、课程成员和对象权限校验；学生只读取本人或本课已发布且有参与资格的对象。成功响应使用 `data` 与 `request_id`；失败响应使用 `error.code/message/details` 与 `request_id`。写操作以服务器时间、版本和状态为准，不信任客户端推断。

接口按课程/身份、资源、备课、知识、题目与随堂测、实验版本/连线、电路评测、统计与智能功能分组。文件内容读取区分 `intent=view|download`，访问事件按 `event_id` 去重；公开练习、试卷、错题和备课关联共用题目保密检查。备课 `quiz_ids` 仅关联本课 quiz，备课发布要求 quiz 已发布，但不能自动发布或提前显示题干/解析。学习进度分子与分母取同一当前已发布知识点集合；分析查询固化 `analysis_run_id`，CSV 不重新计算。

2026-10-20知识图文提案见[APIC§3.2](../docs/APIC.md#32-spec-005图文增量提案2026-10-20待复核实施)：结构化images固定本课guide图片版本、知识与资源双重当前权限、复用003事件事务；现行HTML禁图/禁属性保持。PNG/JPEG上传和知识关系尚未实现，UUID非法输入实际失败及双方准备见[记录](../docs/SPEC-005_IMAGE_CONTRACT.md)。本条是待复核增量摘要，不宣称新端点可用。

SPEC-017 的动作保存、结构校验、功能提交，SPEC-018 的 `.circ` 上传、队列、真实运行、报告和教师重评均需按 APIC 第 6—7 节实现。界面只显示实际后端状态；保密答案、原始隐藏测试和跨课程文件不得经任何摘要接口旁路。逐规格入口见 [specs](../specs/README.md)。
