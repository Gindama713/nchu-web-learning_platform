# SPEC-017 实验箱连线过程模拟 · wireframes（界面设计）

[PRD 统一验收](../../docs/PRD.md#accept-spec-017) · [接口契约](../../docs/APIC.md) · [数据库设计](../../docs/DBD.md) · [架构决策](../../docs/ADR.md)

核心界面：实验箱端子、导线、输入开关与运行记录。这是交互草图与状态要求，不是浏览器验收证据。

主流程：选发布实验 → 接线/断线/开关/时钟 → 保存重开 → 结构校验与功能提交。

```text
┌─ 课程与角色导航 ──────────────────────────────┐
│ 实验箱端子、导线、输入开关与运行记录 │
├─ 筛选/当前状态 ───────────────────────────────┤
│ 选发布实验 → 接线/断线/开关/时钟 → 保存重开 → 结构校验与功能提交。 │
└────────────────────────────────────────────────┘
```

教师只见本课管理与统计；学生只见本人获授权的已发布内容。动作提交前显示窗口、权限和版本状态；提交后显示服务器返回的结果与 ID。空样本、未开始/已截止、无权限、校验失败和服务不可用需有独立提示，不得用零分或空白页代替。移动端保持可读和键盘可操作。

工作区分为器件/端子、连线画布、输入与时钟控制、动作历史、结构/功能反馈五区；保存后重进应恢复同一版本与过程。
