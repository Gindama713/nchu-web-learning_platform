# SPEC-020 教学助手界面设计

登录并选课 → 顶部教学助手页签 → 推荐问题或输入 → 提问 → 回答标题、文字、事实卡片、可选图表、局限说明与动作按钮。

教师查询单个学生后，输入框上方显示「正在问：姓名」和清除入口；「他/她」接续该学生，清除或切换课程后不沿用旧目标。学生端不提供目标学生选择。

加载时阻止重复提交；失败时显示错误并允许重试。无匹配时显示四个澄清候选；无数据保留原因说明，隐藏空图。知识检索相似度明确区别于答题正确率。

图表复用 `charts.js`：考勤构成为环形，知识薄弱项为横条，多周到勤为折线。悬停提供标签与数值，动画遵守 `prefers-reduced-motion`。现场步骤见 [演示脚本](../../docs/DEMO_SCRIPT_ASSISTANT_20261120.md)。
