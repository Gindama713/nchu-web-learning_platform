# SPEC-005 课程知识 · wireframes（界面设计）

[PRD 统一验收](../../docs/PRD.md#accept-spec-005) · [接口契约](../../docs/APIC.md) · [数据库设计](../../docs/DBD.md) · [架构决策](../../docs/ADR.md)

核心界面：章节目录、知识点阅读与收藏。这是交互草图与状态要求，不是浏览器验收证据。

主流程：教师维护章节与知识点 → 发布 → 学生检索、阅读、收藏并记录完成。

图文待复核交互：教师在正文后/例题后选本课guide图片的固定版本，编辑纯文本alt/caption并排序；发布前显式公开所需资源，保存失败保留表单。学生仅经知识上下文当前权限取图，缺文件/资源撤权显示通用占位，知识撤回/课程撤权清除详情和旧图；网络重试复用逻辑UUID。当前界面尚无这些控件，不能作为可用截图；细节见[APIC§3.2](../../docs/APIC.md#32-spec-005图文增量提案2026-10-20待复核实施)。

```text
┌─ 课程与角色导航 ──────────────────────────────┐
│ 章节目录、知识点阅读与收藏 │
├─ 筛选/当前状态 ───────────────────────────────┤
│ 教师维护章节与知识点 → 发布 → 学生检索、阅读、收藏并记录完成。 │
└────────────────────────────────────────────────┘
```

教师只见本课管理与统计；学生只见本人获授权的已发布内容。动作提交前显示窗口、权限和版本状态；提交后显示服务器返回的结果与 ID。空样本、未开始/已截止、无权限、校验失败和服务不可用需有独立提示，不得用零分或空白页代替。移动端保持可读和键盘可操作。
