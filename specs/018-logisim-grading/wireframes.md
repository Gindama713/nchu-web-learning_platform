# SPEC-018 Logisim 在线评测 · wireframes（界面设计）

[PRD 统一验收](../../docs/PRD.md#accept-spec-018) · [接口契约](../../docs/APIC.md) · [数据库设计](../../docs/DBD.md) · [架构决策](../../docs/ADR.md)

核心界面：.circ 上传、排队状态、评测报告与教师重评。这是交互草图与状态要求，不是浏览器验收证据。

主流程：选发布实验 → 上传 .circ → 查看队列/运行 → 浏览判分报告与重评历史。

```text
┌─ 课程与角色导航 ──────────────────────────────┐
│ .circ 上传、排队状态、评测报告与教师重评 │
├─ 筛选/当前状态 ───────────────────────────────┤
│ 选发布实验 → 上传 .circ → 查看队列/运行 → 浏览判分报告与重评历史。 │
└────────────────────────────────────────────────┘
```

教师只见本课管理与统计；学生只见本人获授权的已发布内容。动作提交前显示窗口、权限和版本状态；提交后显示服务器返回的结果与 ID。空样本、未开始/已截止、无权限、校验失败和服务不可用需有独立提示，不得用零分或空白页代替。移动端保持可读和键盘可操作。

上传区显示文件限制与版本；提交后只展示真实队列/运行/终态，报告区区分学生错误和系统故障，教师重评保留旧记录。
