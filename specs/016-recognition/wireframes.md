# SPEC-016 识别辅助 · wireframes（界面设计）

[PRD 统一验收](../../docs/PRD.md#accept-spec-016) · [接口契约](../../docs/APIC.md) · [数据库设计](../../docs/DBD.md) · [架构决策](../../docs/ADR.md)

核心界面：图片识别预览、置信度与人工确认。这是交互草图与状态要求，不是浏览器验收证据。

主流程：上传标准图片 → 查看坐标与置信度 → 人工确认草稿，不直接运行或评分。

```text
┌─ 课程与角色导航 ──────────────────────────────┐
│ 图片识别预览、置信度与人工确认 │
├─ 筛选/当前状态 ───────────────────────────────┤
│ 上传标准图片 → 查看坐标与置信度 → 人工确认草稿，不直接运行或评分。 │
└────────────────────────────────────────────────┘
```

教师只见本课管理与统计；学生只见本人获授权的已发布内容。动作提交前显示窗口、权限和版本状态；提交后显示服务器返回的结果与 ID。空样本、未开始/已截止、无权限、校验失败和服务不可用需有独立提示，不得用零分或空白页代替。移动端保持可读和键盘可操作。
