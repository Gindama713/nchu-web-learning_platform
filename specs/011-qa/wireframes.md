# SPEC-011 智能问答 · wireframes（界面设计）

[PRD 统一验收](../../docs/PRD.md#accept-spec-011) · [接口契约](../../docs/APIC.md) · [数据库设计](../../docs/DBD.md) · [架构决策](../../docs/ADR.md)

核心界面：提问、检索片段与出处。这是交互草图与状态要求，不是浏览器验收证据。

主流程：输入 CPU 问题 → 展示真实相似度、已发布片段和出处 → 无结果提示。

```text
┌─ 课程与角色导航 ──────────────────────────────┐
│ 提问、检索片段与出处 │
├─ 筛选/当前状态 ───────────────────────────────┤
│ 输入 CPU 问题 → 展示真实相似度、已发布片段和出处 → 无结果提示。 │
└────────────────────────────────────────────────┘
```

教师只见本课管理与统计；学生只见本人获授权的已发布内容。动作提交前显示窗口、权限和版本状态；提交后显示服务器返回的结果与 ID。空样本、未开始/已截止、无权限、校验失败和服务不可用需有独立提示，不得用零分或空白页代替。移动端保持可读和键盘可操作。
