# SPEC-007 课堂演示 · wireframes（界面设计）

[PRD 统一验收](../../docs/PRD.md#accept-spec-007) · [接口契约](../../docs/APIC.md) · [数据库设计](../../docs/DBD.md) · [架构决策](../../docs/ADR.md)

核心界面：教师投屏控制与学生同步视图。这是交互草图与状态要求，不是浏览器验收证据。

主流程：教师选预设并单步/复位 → 服务端更新 revision → 学生只读同步投屏。

```text
┌─ 课程与角色导航 ──────────────────────────────┐
│ 教师投屏控制与学生同步视图 │
├─ 筛选/当前状态 ───────────────────────────────┤
│ 教师选预设并单步/复位 → 服务端更新 revision → 学生只读同步投屏。 │
└────────────────────────────────────────────────┘
```

教师只见本课管理与统计；学生只见本人获授权的已发布内容。动作提交前显示窗口、权限和版本状态；提交后显示服务器返回的结果与 ID。空样本、未开始/已截止、无权限、校验失败和服务不可用需有独立提示，不得用零分或空白页代替。移动端保持可读和键盘可操作。
