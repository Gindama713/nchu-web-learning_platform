# SPEC-004 课前备课 · wireframes（界面设计）

[PRD 统一验收](../../docs/PRD.md#accept-spec-004) · [接口契约](../../docs/APIC.md) · [数据库设计](../../docs/DBD.md) · [架构决策](../../docs/ADR.md)

核心界面：备课编辑、发布、学生预习入口。这是交互草图与状态要求，不是浏览器验收证据。

主流程：教师编辑关联知识/资源/题目/随堂测 → 校验发布 → 学生阅读预习入口。

```text
┌─ 课程与角色导航 ──────────────────────────────┐
│ 备课编辑、发布、学生预习入口 │
├─ 筛选/当前状态 ───────────────────────────────┤
│ 教师编辑关联知识/资源/题目/随堂测 → 校验发布 → 学生阅读预习入口。 │
└────────────────────────────────────────────────┘
```

教师只见本课管理与统计；学生只见本人获授权的已发布内容。动作提交前显示窗口、权限和版本状态；提交后显示服务器返回的结果与 ID。空样本、未开始/已截止、无权限、校验失败和服务不可用需有独立提示，不得用零分或空白页代替。移动端保持可读和键盘可操作。
