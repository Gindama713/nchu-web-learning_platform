# SPEC-008 随堂测 · wireframes（界面设计）

[PRD 统一验收](../../docs/PRD.md#accept-spec-008) · [接口契约](../../docs/APIC.md) · [数据库设计](../../docs/DBD.md) · [架构决策](../../docs/ADR.md)

核心界面：限时答卷、统计与讲评。这是交互草图与状态要求，不是浏览器验收证据。

主流程：教师发布窗口 → 学生限时提交 → 教师逐题统计 → 显式讲评后才展示解析。

```text
┌─ 课程与角色导航 ──────────────────────────────┐
│ 限时答卷、统计与讲评 │
├─ 筛选/当前状态 ───────────────────────────────┤
│ 教师发布窗口 → 学生限时提交 → 教师逐题统计 → 显式讲评后才展示解析。 │
└────────────────────────────────────────────────┘
```

教师只见本课管理与统计；学生只见本人获授权的已发布内容。动作提交前显示窗口、权限和版本状态；提交后显示服务器返回的结果与 ID。空样本、未开始/已截止、无权限、校验失败和服务不可用需有独立提示，不得用零分或空白页代替。移动端保持可读和键盘可操作。
