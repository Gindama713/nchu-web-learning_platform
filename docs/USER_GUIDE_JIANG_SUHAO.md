# 姜苏豪负责模块使用说明

适用 SPEC-001、002、010A、014、016。本文按当前页面与接口说明可执行操作；实际验证层级见[个人测试报告](TEST_REPORT_JIANG_SUHAO.md)，部署步骤以[README 第 8 节](../README.md#8-本地运行与验证)为准。教师及学生使用前，由管理员完成数据库迁移、创建真实账号、设置课程和成员；不要把演示密码写入仓库。

## 账号、角色与课程

开发环境启动 API 与前端后，浏览器打开 `http://127.0.0.1:5173`。学生可用完整学号自行注册并登录；教师角色只由管理员授予。管理员先授予教师角色，再创建课程并指定任课教师。教师选中本人课程后，在“课程成员”输入学生完整学号加入，列表显示在课与已移出状态；移出会撤销当前课程访问，历史冻结名单和成绩保留。课程负责人移交由管理员执行，不能只修改展示字段。

切换课程或退出后，页面清空上个课程的明文签到码、考勤统计、识别草稿和筛选条件。若请求返回登录失效或课程无权，重新登录或请管理员核对成员关系；不要靠修改浏览器中的课程 ID 访问他人数据。管理员停用账号后旧会话失效，至少保留一位有效管理员。

## 教师发起考勤与学生处理

1. 教师选课，填写任务标题、开始、迟到界限、结束时间并发布。页面在创建响应中显示六位签到码；保存到课堂受控渠道。普通列表不会再次返回明文码，关闭页面或切课后需在允许的时间内轮换新码。
2. 在开放窗口内可轮换签到码；旧码立即失效。学生选中该课程，在考勤任务输入任务 ID 和六位码签到。重复提交返回原有效记录，不生成第二条。时间窗口和迟到判定以服务器为准。
3. 学生可对任务提交请假理由；教师在课程请假列表审批并填写理由。驳回后学生可修改重提，已批准请假需按页面提示给出撤销理由与恢复状态。教师关闭任务后才结算缺勤；更正记录时必须写原因，系统保留审计并通知学生。

任务发布时冻结在课参与人。后来加入不补历史缺勤，移出者不从历史应到人数中删除。错误码、过期码或关闭后的新签到按接口报错处理；不要为了补签重开历史任务，使用有理由的教师更正流程。二维码只是六位令牌的展示方式，当前文档不把实体扫码设备实测记为通过。

## 教师统计与预警

在“考勤与成绩关联”按需选择时间段和本课测评卷 ID，点击“生成统计快照”。页面显示到勤率、有效成绩均值、相关系数或无效原因、样本数和周趋势。相关性至少需要三名同时有到勤率与已评分成绩的学生；没有样本显示“无数据”，不能把待批或缺交当零分。教师可从当前快照链接导出同一 `analysis_run_id` 的 CSV。若需恢复旧快照，按[APIC 统计接口](APIC.md)用原 ID 查询；当前首页没有旧快照编号输入控件。学生仅可查询本人的考勤维度，不得到全班配对名单。

教师在“学习预警”手动生成批次，查看每条原因、样本数和值；样本不足时仍可显示有证据的规则提示，但不产生强行聚类结论。对已处理项填写记录。预警只供教师辅助判断，不自动处分或扣分。要复核历史结论，应记下批次和来源截止；补录成绩或更正考勤后生成新批次，不静默改写旧批次。

## 实验图辅助识别

在当前课程上传 PNG/JPEG 标准白底黑色、正向印刷门符号图片。页面显示 AND、OR、XOR、NOT 的符号框、已知标签框、模板相似度和低/高标记。低置信度、未知标签均须人工核对；可在 JSON 草稿中修改或删除已有识别项后确认。无法识别时改用实验手工建模入口，不能通过确认接口凭空添加原图未检出的门。确认只保存结构草稿，不生成可信电路，也不进入实验连线或 Logisim 成绩。手绘、旋转、一般照片不属于固定样例验证范围。

## 故障与证据边界

| 页面现象 | 处理方式 |
|---|---|
| 无课程或成员权限 | 由管理员或任课教师核对角色、成员和课程负责人；重新登录读取当前权限 |
| 签到码不显示或旧码失效 | 教师在开放窗口轮换，向本课学生发送新码；不要从历史响应找码 |
| 统计为 null 或相关性无结果 | 核对关闭任务、已评分卷、时间范围和有效配对人数；看返回的 `correlation_reason` |
| 预警 `insufficient_data` | 查看有证据的规则原因；收集真实作答、实验和考勤事实后重跑 |
| 图片 `unrecognized` 或确认失败 | 改用支持的标准图片，核对 JSON 枚举与框；无法识别则走手工建模 |

本说明只覆盖本人模块。真实 Logisim worker、目标部署、备份恢复和完整系统用户手册由全组按统一[README](../README.md)及[发布回滚手册](CHG-RB.md)验证。
