## 2 职责、架构与数据边界

前端采用 Vue 3，后端采用 Flask RESTful API，持久层为 SQLite。共享身份和课程授权在服务端执行，前端隐藏按钮不是安全边界。公共迁移 runner 管理 schema 和校验和；统计基于真实考勤、试卷、作答与实验事实，不能为演示伪造业务表。OpenCV 只识别受限的标准门符号，不声称理解整张电路。GitHub 用于日常开发和 CI，Gitea 用于课堂归档，两个仓库需核对同一提交 SHA。

## 3 用户、课程与考勤设计

学生可注册，教师和管理员身份只能由受控管理员操作授予。密码以适合密码存储的哈希保存，会话使用服务端版本约束，停用或改密后旧会话失效。课程成员和角色构成所有课程数据的授权边界；教师只管理自己负责的课程，学生不能访问他人记录或跨课数据。写操作要求 Origin 和 CSRF，事务中重新检查会话与课程资格，避免读取权限和提交事实之间发生撤权竞态。

考勤任务发布时冻结在课学生集合，之后转入者不补历史缺勤，退出者不改变历史应到分母。签到码采用六位数字且仅创建或轮换响应返回一次；数据库保存哈希，普通查询不返回明文。学生在有效时窗内签到，重复或并发请求只能产生一条有效记录；轮换后旧码不能再用。关闭任务才结算缺勤。请假申请、驳回重提、批准撤销及教师有理由更正均保留记录与通知，四种有效考勤状态互斥。

教师页面显示当前课程成员和状态，可按完整学号添加、移出。课程切换或退出会清除签到明文、表单和统计结果；异步响应带课程代际检查，避免上一课程的查询结果写入新课程界面。成员查找期间若已换课，前端不将查到的学生误加到另一课程；服务端仍负责最终授权。

## 4 考勤统计与学习预警

010A 选择同一时间区间内已关闭任务的冻结参与人，计算应到、出勤、迟到、请假、缺勤；到勤率为出勤加迟到除以应到，空分母返回 null。测评只使用本课程、已发布、区间内的作业、考试或随堂测，成绩只取已评分有效答卷。学生多卷成绩先转换为百分比，再取等权均值；待人工评分、缺交、部分成绩不当零分。相关分析以同一个学生的到勤率和有效成绩配对；不足三人、任一维零方差分别返回明确原因。

固定验收 C01 有三名学生正常配对，相关系数为 1；C02 少于三名有效配对返回 null；C03 零方差返回 null；C04 的第四名学生缺少已评分卷，不填假零分，班级到勤率仍包含其应到。学生请求仅可看本人指标，不能泄露班级配对名单。计算前冻结数据，保存参数、来源截止、算法版本、指标、样本与周趋势到 analysis_run。接口可按原 ID 恢复，CSV 导出也读取原快照；当前首页只提供新快照和当前快照导出入口。后续考勤更正或人工批分不静默改写旧报告。

014 在 28 天窗口内以真实客观作答正确率、到期实验完成率、关闭任务考勤率形成特征。客观题少于五次不进行成绩风险推断，最近两次考勤迟到或缺勤仍可提示。只有至少十名三项均有分母且特征行有区分的学生才运行固定参数 KMeans；否则 model_status 为 insufficient_data，仅展示有证据的规则原因。一个班全员表现良好时不强制产生风险提示。预警是教师辅助信息，可标记已处理，不自动处分或扣分。

## 5 受限识别与人工确认

016 仅接受受控大小的 PNG/JPEG，并校验真实格式、尺寸与可解码内容。灰度小于 128 为前景；先以固定形态学核定位正向门符号与印刷标签，再裁白边、最近邻缩放到 64×64，以前景交并比和固定模板匹配。0.55 以下不输出已识别项，0.55 至小于 0.85 为低置信度，0.85 及以上为高置信度；判断用未舍入值，返回值保留六位。置信度是模板相似度，不是“识别正确概率”。

本次将 F01 清晰 AND/NOT、F02 残损 AND、F03 电阻、F04 未知 XYZ 标签、F05 空白五张 640×240 PNG 连同 SHA-256 固定在仓库。测试同时检查类别、门框和标签框的像素容差、阈值边界与服务端上传流程。原规划的 v1 图像只有哈希没有实际文件，因此按变更规则改为 v2 固定字节，不冒称验证了不存在的 v1 输入。任何识别项均需本人确认，可删改原有项并补字典内标签；确认不生成可运行电路，不触发连线或 Logisim 成绩。

## 6 工程协作、验证与交付边界

采用 feature 分支开发，经 PR 合入 develop；发布准备从 develop 拉 release，完整门禁通过后再 PR 到 main，main 禁止直推。Actions 分开执行文档规则、lint、后端与前端测试、构建和真实评测冒烟，聚合门禁不能把失败或跳过误判为成功。发布还需在目标环境验证 Java 21、固定 Logisim JAR、评测 worker、数据库与上传文件一致备份、恢复、维护模式及真实闭环。只有部署冒烟成功后才开放普通写入；最后按相同 SHA 归档 Gitea。

本地检查入口为 `python -m unittest discover -s tests -v`、`python scripts/check_docs.py`，以及前端 `npm test`、`npm run lint`、`npm run build`。本人测试重点检查登录/权限/撤权、冻结名单和重复签到、010A C01—C04 与同快照 CSV、014 样本不足与真实事实、016 固定 PNG/阈值/HTTP 确认和成绩隔离。受控浏览器另验证教师登录、成员列表、无数据统计快照和切课状态清理。具体测试函数与尚缺的课堂证据写在 `docs/TEST_REPORT_JIANG_SUHAO.md`，不能用旧提交的绿色检查代替最终提交。

第 2 阶段课堂可展示本人基础模块；第 3 阶段展示 010A 独立统计；第 4 阶段提交并发幂等、预警和图像识别作为难点候选，是否计分由教师检查决定。个人报告格式附件尚未提供，此 Word 版为内容与版式可审阅的准备稿；课堂要求的最终模板、真实教学数据、全组连线及真实电路评测、50 会话目标环境、备份恢复和 Gitea 提交证明需按真实结果续填，不伪写通过。
