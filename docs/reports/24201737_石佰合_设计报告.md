本材料按现有规格、代码与测试协助整理，个人设计取舍、课堂演示和贡献说明须本人复核后独立提交。范围为 SPEC-003 教学资源、SPEC-009 实验辅助与电路实验台、SPEC-018 电路在线评测及 SPEC-010D 评测统计。

## 1 需求与职责

教学资源提供教师上传、版本留存、学生访问与使用统计；实验辅助提供已发布指导与实验版本，电路实验台提供芯片功能计算与后台数据就绪状态；在线评测将学生电路交给独立 worker 执行，记录可重放判分结果；统计分别展示教学结果与运行可靠性，避免将系统故障算成学生能力问题。

主规格为 `docs/PRD.md`、`docs/APIC.md`、`docs/DBD.md` 及对应 `specs/003-resources`、`009-experiments`、`018-logisim-grading`、`010d-grading-analytics`。这些文件约束接口、数据字段与验收，本文解释实现，不新增业务规则。

## 2 教学资源设计

`backend/apis/resources.py` 校验资源类别、媒体类型、非空内容与大小，计算 SHA256，以随机存储键落盘。资源文件先写临时文件再替换，文件名不作为服务器路径。课件、指导、题库上限为 20 MiB，视频上限为 100 MiB；权限以课程成员和教师身份为准。

资源更新形成版本，旧版本可追溯；访问事件依事件键去重，HEAD 与 304 不当作新消费。题库导入复用习题模块校验并保持事务原子性与幂等性，不能部分写入后声称整批成功。

## 3 实验辅助与实验台

`backend/apis/experiments.py` 维护实验及发布版本，提交关联具体版本。`backend/apis/circuit_lab.py` 提供 spec、compute、table 与 bootstrap：前三项为公开的纯计算/定义入口，bootstrap 需登录，避免匿名枚举后台表。`data_ready` 检查既有业务事实表，不另建影子数据。

实验台的芯片功能表由后端权威求值，前端按 spec 绘制 SVG 引脚与连线；例如 7485 比较器拒绝布尔值、非整数及越界操作数，以 400 代替位运算异常造成的 500。界面模拟与服务器求值需通过同一功能样例复核。

## 4 电路在线评测

`backend/apis/grading.py` 校验电路提交、测试套件、幂等键与课程权限；`backend/engines/grading.py` 处理租约队列、子进程执行、输出解析和故障恢复。测试用例区分公开/隐藏，学生查询不可泄漏隐藏期望。

worker 租约 30 秒，每 5 秒续租；续租与提交结果均检查任务状态、token 及当前时间严格早于租约截止。过期 worker 不得覆盖新任务。真实执行使用参数数组调用 `java -Xmx… -jar … -o en -w …`，不拼 shell；固定 Logisim 5.0.0 JAR 由 `LOGISIM_JAR_PATH` 指定，CI 另核 SHA256。该引擎路径会使用 Swing，Linux CI 用 xvfb，不强制 Java headless。

输入预检、元件白名单、超时、内存/输出/进程限制与错误状态各有独立路径。系统错误与零用例不能伪装为学生电路判错；重评新建运行记录，旧快照不被覆盖。

## 5 评测统计

`backend/models/grading_analysis.py` 读取真实 submission 与 grading_run 事实，按既有 SPEC-010D 规则选择有效成绩。教学通过率与可靠性分开展示，queued 与 system_error 不替换既有有效成绩；超时和资源限制按规格记零分。无样本返回 null，不用 0% 冒充统计结果。

统计接口保存 `analysis_run` 快照，恢复与 CSV 导出读取同一快照；重评或成员退出后，历史分母与已生成快照仍可复核。

测试入口及本轮结果见 [个人测试报告](../TEST_REPORT_SHIBAIHE.md)，操作见 [用户手册](../USER_GUIDE_SHIBAIHE.md)，阶段状态见 [检查点](../checkpoints/SHIBAIHE_2026-11-23.md)。接口集成测试使用真实路由与数据库；worker 结果注入不等于真实 Java 引擎执行。真实引擎必须另看 `scripts/ci_grader_smoke.py` 与当前 PR 的 ci-grader。
