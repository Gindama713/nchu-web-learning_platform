# 石佰合负责模块用户手册

适用：SPEC-003、009、018、010D。按当前界面和接口协助整理，须负责人复核。启动、数据库初始化与依赖安装先按根目录 README；真实电路判分还需 Java、固定 Logisim JAR 和独立 worker。

## 1 教师准备资源与实验

教师登录并选择自己管理的课程，在教学资源页上传课件、视频、指导或题库，选择正确类别并确认发布。视频不超过 100 MiB，其他资源不超过 20 MiB。更新资源后检查新版本及旧版访问，不把上传成功等同于学生已可见；学生可见性仍受发布状态与备课关联约束。

在实验辅助页选择实验模板，填写实验时间窗、提交方式与指导并发布。电路实验台可查看芯片、引脚、功能表和验证状态；后台缺数据时先按提示初始化，不能只隐藏提示。

## 2 学生提交电路

学生登录并选择已加入的课程，打开已发布且处于提交窗口的实验，查看公开测试说明，选择允许的 `.circ` 文件提交。保留提交编号，等待 queued/running 变为终态后查看自己的结果；刷新或重试应使用界面原流程，避免另建重复提交。

若长期排队，教师检查 worker 与 `LOGISIM_JAR_PATH`；若为 system_error，先看运行故障，不能解释为学生得零分。教师可按原接口重评，重评会留下新的运行记录。学生不得查询他人的提交或隐藏测试期望。

## 3 教师查看统计与导出

在统计页选择评测维度、时间区间与可用筛选条件，生成统计，记录 `analysis_run_id`。核对通过率、测试套件分布与可靠性；空样本应显示无数据。使用同一快照导出 CSV，再与页面数字逐项对照。重评后可以生成新统计，但旧快照应保持不变。

## 4 演示取证

使用教师和学生两个独立会话，依次记录资源上传与旧版、实验发布、学生排队及结果、越权拒绝、统计及同快照导出。截图遮盖真实学生信息与令牌；当前尚未完成这些现场取证，记录位置为 `docs/checkpoints/SHIBAIHE_2026-11-23.md`。
