## 实现与可审阅接入

`backend/models/knowledge.py`承担固定字段验证、富文本白名单、同课权限复核及短事务。新增/排序锁内校验课程revision，完整ID集合先校验，再移至不冲突临时非负位置，最后写0至n−1及递增revision。数据库唯一约束是并发防线。数据库忙等待5秒后503，不无限重试。知识下架保留收藏/进度及引用；学生列表、详情及个人写入均检查当前发布状态。

`backend/apis/knowledge.py`提供APIC的10个005入口，已注册到app。安全适配器缺失503，迁移缺失/校验失败503。输入user_id/role等未知字段拒绝；测试替身只在tests/test_knowledge.py的临时Flask实例中使用。

模块迁移由公共runner在事务内调用，005不提供无鉴权初始化命令。runner必须在相同事务登记schema_migration，重复执行核对版本/校验和再跳过，失败全量回滚。实际公共runner尚未对接，不能在生产执行本模块或承诺恢复演练通过。
