# 罗浩铭负责模块使用说明

适用 SPEC-004 备课、SPEC-007 课堂演示、SPEC-017 实验箱连线、SPEC-010C 连线统计、SPEC-015 先修图谱。本文按当前页面与接口说明可执行操作；验证层级见[个人测试报告](TEST_REPORT_LUO_HAOMING.md)，部署步骤以 [README 第 8 节](../README.md#8-本地运行与验证) 为准。教师与学生使用前，由管理员完成迁移、建号、建课与成员授权；不要把演示密码写入仓库或提交到版本库。

**2026-11-09 核对**：本文按 `develop` 当前页面修订，11-05 版所述「教学内容下有两个同名知识图谱卡片」已不再成立；11-08 的本地修复尚未合入 `develop`，下述操作路径描述的是主干行为。

## 角色、入口与一个必须先说的限制

浏览器打开 `http://127.0.0.1:5173`，API 由 Vite 代理到 `127.0.0.1:5000`。学生可自行注册；教师角色只能由管理员授予，课程负责人由管理员移交。

**管理员登录看不到本人这五个模块。** `frontend/js/main.js` 中五个组件均带 `user.role !== 'admin'` 条件，管理员的分区导航只有第一项。检查与演示必须使用教师或学生账号，这是既有设计，不是权限故障。

页面顶部五个分区：课程与通知、教学内容、测评与练习、实验与演示、考勤与学情。本人模块分布在其中三个分区：

| 模块 | 分区 | 卡片位置 | 可写角色 |
|---|---|---|---|
| 015 先修图谱 | 教学内容 |「知识图谱」（点节点聚焦子图、「添加关系」表单、传递闭包开关） | 教师加边，师生均可查询 |
| 004 备课单元 | 教学内容 | 最底部「备课单元」 | 教师 |
| 007 课堂演示 | 实验与演示 | 第一张「课堂演示」 | 教师推进，学生跟随 |
| 017 实验箱连线 | 实验与演示 | 第三张「实验箱连线」 | 学生操作，教师只读 |
| 010C 连线统计 | 考勤与学情 | 倒数第二张「连线统计」 | 仅教师 |

「教学内容」分区现只有一张「知识图谱」卡片，由 `frontend/js/knowledge-graph-view.js` 实现（分层布局、先修箭头、传递闭包、点节点只看相关子图、教师建边）。本人命名的 `graph-view.js` 未进入 `develop`，只在远端 `origin/integration/final-20261029`；讲解时按「主干组件已承接图谱功能，但本人同名文件未合入」说明，不要声称二者是同一实现，也不要再按「两个视角」介绍。

## 004 备课单元

1. 教师进入教学内容 → 备课单元 → 新建备课，填写标题与排期，勾选关联的知识点、资源、题目与随堂测。
2. 点「创建草稿」后单元仅教师可见；草稿可继续编辑。
3. 展开该条点「发布」，再点「确认发布」，学生端出现通知；已发布单元不可直接改写，需先撤回再重新发布。
4. 「复制」生成新的草稿，原单元与其发布事实不变，适合按周复用的模板场景。
5. 已发布单元可填写理由后撤回，撤回后学生不再可见，历史记录保留。

关联的随堂测未发布时，创建或发布返回 409 `QUIZ_NOT_PUBLISHED`，按提示先发布随堂测，不要绕过校验直接改库。

## 007 课堂演示

1. 教师进入实验与演示 → 课堂演示，选择课程与场景（门电路、组合逻辑、时序逻辑、运算器、存储器、指令执行）。
2. 点「开始新演示」创建会话，用「单步」「连续运行」「暂停」「复位」推进；头部显示当前拍数、所处阶段与停机标记。
3. 学生端打开同一卡片，约每 2 秒拉取服务端状态，画面以服务端 `state` 为准，不在前端自行推算。
4. 课堂结束点「结束演示」；「本课程演示记录」可按条查看历史会话。

两人同时推进时，后提交的一方会收到 409 `REVISION_CONFLICT`，页面提示重新加载。这是并发保护，不是故障；学生端只读，不参与推进。

## 017 实验箱连线（重点）

1. 进入实验与演示 → 实验箱连线，选择课程与已发布实验版本（EXP-01/02/03），点「发起连线」。
2. 端子表列出每个端子的方向与位宽。连线画布左侧选输出、右侧选输入，点「连接」；方向相反或位宽不一致会被拒绝，修正后重连。
3. 输入时钟区选择 SWITCH 类端子写入数值并点「写入」，该动作与连线动作一起进入动作序列。
4. 「单步」推进一拍，「连续」每秒一拍，「复位」回到初态；画布与状态栏同步刷新。
5. 依次点「保存」「校验」「提交」。提交响应含功能判定表，逐条列出期望值与实际值；`completed` 为真表示全部通过。
6. 提交后该尝试不可再编辑；重新连线须发起新的尝试。教师在同一卡片只能查看学生记录，不能代替学生操作。

保存、校验、提交均带 revision。页面停留在旧状态时提交会返回 409 `REVISION_CONFLICT`，按提示「重新加载」后再操作；不要在旧画布上反复点提交。实验窗口关闭后操作返回 409 `WINDOW_CLOSED`，需要教师重新发布窗口。

## 015 先修图谱

教师可添加「先修/包含」关系：先修方向表示起点须先于终点学习。写入会检查闭环，成环返回 422 `PREREQUISITE_CYCLE`，这是设计好的负向用例，可当场演示。点任意知识点即只看与它相关的子图，再点一次取消；「显示全部」可恢复全图，「间接先修（传递）」开关显示传递闭包。图谱只表达学习顺序，不参与成绩计算。

## 010C 连线统计

1. 教师进入考勤与学情 → 连线统计，选择课程与统计区间。
2. 点「查询统计」生成快照，显示应做人数、尝试次数、完成人数、完成率与错误类型分布；同一学生多次尝试只计一人，未完成不计入完成率。
3. 生成后可用「恢复原快照」按编号复现同一份结果，「导出当前快照 CSV」导出该快照。

**区间口径必须说明**：统计按实验版本的结束时间把实验归入区间，结束时间不能填未来，窗口未结束的实验不会进入任何区间。演示时若查询不到数据，先确认所选版本已结束，再把统计结束时间填到该实验结束之后；空样本与「0 人完成」是两回事，不能混说。

## 故障与证据边界

| 页面现象 | 处理方式 |
|---|---|
| 看不到本人五个模块 | 确认用教师或学生账号登录；管理员账号按设计不可见 |
| 连线方向/位宽报错 | 依端子表核对方向与位宽，反向或不等宽不允许连接 |
| 409 `REVISION_CONFLICT` | 页面状态落后于服务端，重新加载后再操作 |
| 409 `WINDOW_CLOSED` | 实验窗口已关闭，请教师重新发布 |
| 010C 查询为空 | 核对所选版本是否已结束、统计结束时间是否晚于实验结束 |
| 409 `QUIZ_NOT_PUBLISHED` | 先发布关联随堂测，再发布备课 |
