# 黄俊诚负责模块运行与用户说明

适用005、006、008、010B、011、012、013，材料日期2026-10-16。本文帮助教师和学生完成本人模块的操作，补充已有[README§8](../README.md#8-本地运行与验证)，不替代全系统部署手册。下列是当前实现的操作说明；本轮没有重新执行整套业务，验证范围见[个人测试报告](TEST_REPORT_HUANG_JUNCHENG.md)。

## 启动与账号前提

在开发副本按README§8从仓库根安装锁定依赖、执行公共db-upgrade、创建管理员、启动API和前端。使用README规定的Python3.12+、Node22+，登录地址为 `http://127.0.0.1:5173`；改变前端地址时保持APP_ORIGIN一致。不要把临时数据库、上传文件、密码或Cookie提交到仓库。

管理员、课程、任课教师和当前学生成员由001真实账号/课程流程准备。教师只能管理本人授课课程，学生只能读取当前有权内容。没有课程或权限时先联系课程管理员处理成员关系，不以猜ID、改本地页面或直接改数据库恢复权限。本人指南不提供教学账号密码。

健康检查的数据库就绪与真实评测worker就绪是不同条件：README记录迁移后仍可能503且grader_ready=false。没有worker、Java/JAR校验和、生产备份/部署实测时，不将本地页面可用写成完整系统已部署。生产维护、同点备份与恢复按[CHG-RB](CHG-RB.md)由负责人执行。

## 教师准备知识与题目

1. 登录并选择本人授课课程，在课程知识区创建章节和知识点，填写正文/例题、按需设置基础标记，再发布。基础标记供无作答时的推荐使用。
2. 编辑章节排序时以当前完整章节集合提交；冲突后重新加载再调整，避免覆盖另一教师的操作。知识下架后学生隐藏，历史完成记录保留。
3. 进入题目管理，关联真实同课程知识，按单选、多选、判断、数值或简答类型填写字段并保存。修改形成新版本，历史答卷仍对应原版本。
4. 图文目前不能任意粘贴外部图片或URL。授权图片及003资源引用仍属接缝缺口，以[005限制说明](SPEC-005_IMPLEMENTATION.md)为准；不要通过开放HTML属性绕过。

## 教师编卷发布与讲评

在“课程试卷/随堂测”选用固定题目版本并设置配分，检查草稿后再发布。普通作业/考试按原页面设置开始、截止和讲评时间；专用随堂测只填开始/截止，显式讲评另行操作，不能把截止当作答案开放。

发布冻结当时有效学生名单。之后转入不追加历史应交，退出不抹去历史分母。页面按Asia/Shanghai显示时间，提交受理依服务器窗口；学生本机倒计时只是提示。保密题的所有版本共同受保护，新版本不能洗掉旧公开身份。

教师从原答卷进入人工批阅，对简答整批评分或更正，冲突则重新加载当前revision后操作。专用随堂测可读逐题统计：漏答计分母，缺交按冻结名单计算，简答正确率为“—”，待批不混入已定分均值，多选比例总和可超过100%。截止后尚未讲评时解析继续隐藏；确认准备好讲评后再执行显式讲评，重复操作保留原讲评时刻。

## 学生学习作答与错题

选择课程后检索已发布知识、查看详情、收藏或标记完成。再次登录读取历史；下架内容不可见不代表历史被删除。

从试卷列表或通知进入有权试卷，完成后提交。简答待批时总分可为null，漏答与已批零分不同。若提交已到服务器但响应丢失，保留原答卷和原键使用页面重试，不刷新后换键重复交卷；截止后新提交拒绝并不代表已成功键不能重放。权限变化后仍须重新授权。

在“公开练习与个人错题”选择开放的固定客观版本，提交后查看可见解析。错题按本人题目身份去重，重练正确可标记已掌握，新错会恢复未掌握状态，原作答历史保留。受保密卷占用或未讲评时，题目可能暂不能练习或看答案；等待教师按规定讲评/开放，不用旧版本或历史响应绕过保护。

## 知识与分类成绩分析

进入“知识与分类成绩分析”，选择课程及knowledge/scores维度。学生读本人；教师可读班级，或选择当前本课学生查看个人进度。知识掌握度只计已实际作答的客观样本，零样本为“无数据”；多标签题可分别贡献知识点，总体不重复计数。完成进度使用当前发布知识集合，日期只筛作答，不更换进度分母。

分类成绩按作业/考试/随堂测选择，单卷使用原分，跨卷使用百分比；缺交、待批和已批0分分开。日期按页面本机输入转换，显示结果及周界以报告口径为准，不能把不同时间口径混算。

“查询统计”创建新快照。记下原快照编号，用同一账号/课程“恢复原快照”；教师从当前快照导出CSV。之后批分、更正或新作答不改变旧ID和CSV。读取/导出失败时旧结果清空，显式恢复或重新查询；不要把重新查询的新结果称为原快照恢复。宽表可在容器内滚动并用键盘聚焦。

## 知识检索问答与个人推荐

在问答区输入课程问题，查看匹配的知识片段、出处、相似度、算法版本和语料revision。片段来自已发布知识，不是生成式答案，相似度不是正确概率。无匹配或语料为空时按页面提示调整问题或等待发布；索引失败时旧片段清空，显式重试。知识修改/下架会使旧revision失效，不能继续使用旧片段。

学生在“个人学习推荐”选择数量1—20并刷新。页面说明推荐理由、样本数、掌握度、排序分数及依据截止。没有作答时只推荐未完成的基础知识；完成且样本≥5、掌握度≥80%的项会过滤。空课程、无基础候选和全部掌握各有原因，排序分数不是概率。

“阅读知识”读取当前出处；“去练习”重新核验推荐和当前开放客观版本。没有合格练习可先阅读，不能用旧推荐强制打开已关闭题目。推荐失败清空旧结果后可刷新，原练习链仍可独立使用。

## 教师智能组卷与重放

在“课程试卷/随堂测→智能组卷”填写新标题、题量、总分、难度配额和必选知识点，按需填写seed、历史截止与保密。成功只保存草稿，不自动发布。检查固定版本、知识覆盖和精确配分后，进入“查看草稿与发布设置”走原006/008发布流程。

需要复现时选择“从此快照重放”或填写原快照编号，只给新标题；使用原候选、历史、参数及seed，不因新题库变化重选。原卷不变，发布时仍会重新检查当前资格。400按提示修参数；422调整不可行题量/配额/覆盖；503 SEARCH_LIMIT缩小约束后显式重试，不把预算用尽称为确定无解。未知保存结果先刷新草稿列表确认，再决定是否重试。

## 常见失败与验收边界

| 现象 | 正确处理 |
|---|---|
| 登录失效、课程移除、权限拒绝 | 重新登录或由管理员恢复成员；不要复用旧数据视图 |
| 保存或批阅revision冲突 | 重新加载最新版本，对照修改后再提交 |
| 加载/查询/导出失败 | 旧结果应清空，按页面显式重试；确认快照ID和当前权限 |
| 截止/保密拒绝 | 以服务器状态及实际讲评为准；原成功键重放遵循现行权限 |
| 智能算法暂不可用 | 保留错误原因，按上文纠正输入或重试；不影响已有练习可用性结论的范围见固定测试 |

所有操作仍需真实课堂检查。目标性能、生产完整恢复、图片/资源/备课等跨模块缺口及R47并未由本文关闭；最新交付状态见[材料索引](C12C_DELIVERY_HUANG_JUNCHENG.md)。
