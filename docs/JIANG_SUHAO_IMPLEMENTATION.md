## 关键设计与跨模块契约

身份和课程权限是其他模块的唯一授权入口。写请求先检查会话、课程资格和 CSRF；涉及并发的短事务内重新验证。停用账号和移出课程后不能继续读写该课程；考勤已冻结名单和历史记录不因成员变更重写。教师创建或轮换签到码仅一次响应携带明文，列表和历史响应不再给码。页面切课及退出立即清除明文码、筛选和旧快照，并丢弃已过期的读响应。

010A 只消费已关闭考勤任务的冻结参与人以及本课已发布卷的已评分答卷。每个学生先计算到勤率和有效试卷百分比均值，再以至少三名有效配对学生计算 Pearson 相关；样本不足和零方差分别返回原因，不填造 0 分。统计输入、算法版本、结果及周趋势保存为不可变 analysis_run，导出按原 ID 读取，不能用新数据重算旧快照。学生只看本人指标，不得到全班配对数据。

014 用同课程客观题实际作答、到期实验与关闭考勤事实计算近期特征。少于五次作答不推断成绩风险；十名有效学生或两种特征行不足时仅生成有证据的规则提示。聚类固定 random_state 等参数，并保存批次模型状态与处理记录。题目漏答 `answered=0` 不进入正确率分母；缺少依赖事实表时明确失败，不伪造样本。

016 仅处理白底黑色正向标准 AND、OR、XOR、NOT 和固定端子字典。灰度阈值、形态学核、模板、IoU 匹配及阈值由 [PRD 第 4.5 节](PRD.md#recognition-acceptance) 冻结。识别项输出符号框、已知标签框、置信度和 `low/high`；未知标签必须人工补齐或删除。确认结果只是结构草稿，不进入连线或 Logisim 判分。F01—F05 文件及 SHA 写在 PRD 和 `tests/fixtures/recognition/sha256.json`，`build_fixtures.py` 是可复现生成说明；另有 OR/XOR 标准图回归，避免轮廓分离导致空结果。原计划 v1 图像并未交付，不能称已测。

## 本次可复现检查

后端入口：`python -m unittest discover -s tests -v`。重点类在 `tests/test_identity_attendance.py`、`tests/test_attendance_analytics.py`、`tests/test_warnings.py`、`tests/test_warning_facts.py`、`tests/test_recognition.py`，固定图像 HTTP 上传及确认也在测试中。前端从 `frontend` 执行 `npm test`、`npm run lint`、`npm run build`；文档从根目录执行 `python scripts/check_docs.py`。CI 定义在 `.github/workflows/ci.yml`，PR 的实际绿色状态以对应 head 的 Actions 结果为准，不引用旧 head 代替。

本机受控浏览器使用临时 SQLite、合成管理员/教师/学生和两个测试课程。教师登录后能看到在课成员；生成空数据 010A 快照返回 null 指标、`insufficient_pairs` 和周趋势；切至另一课程后旧快照与筛选不显示。这是界面冒烟，不代表真实班级完整链路或目标 Linux 部署。测试数据库及登录材料保留在被 Git 忽略的 `instance` 下，不随交付提交。
